📋 GIAI ĐOẠN 2: DATABASE & MODELS
================================================================================

[ ] 2.1 - Kết nối MongoDB
    File: src/config/database.js
    Hàm:
      - connectDB(): Promise<void>
      - disconnectDB(): Promise<void>
      - getConnection(): Mongoose.Connection

[ ] 2.2 - Model Đơn Hàng (Order)
    File: src/models/Order.js
    Trường schema:
      - orderId (string, unique, required)
      - metadataHash (string, required)
      - status (enum: CREATED, CONFIRMED, SHIPPED, DELIVERED, CANCELLED)
      - adminAddress (string, required)
      - createdAt (timestamp, auto)
      - updatedAt (timestamp, auto)
      - lastBlockSync (number)
      - txHash (string)

[ ] 2.3 - Model Nhật ký Trạng thái (StatusLog)
    File: src/models/StatusLog.js
    Trường schema:
      - orderId (ref to Order)
      - status (string)
      - timestamp (date)
      - detailsHash (string)
      - updatedBy (address)

[ ] 2.4 - Model Sự kiện Blockchain (BlockchainEvent)
    File: src/models/BlockchainEvent.js
    Trường schema:
      - eventName (OrderCreated, OrderStatusUpdated, etc.)
      - orderId (string)
      - blockNumber (number)
      - txHash (string)
      - indexed (boolean)
      - timestamp (date)
      - data (JSON)

[ ] 2.5 - Model Người dùng (User)
    File: src/models/User.js
    Trường schema:
      - address (wallet address, unique)
      - role (admin, user, viewer)
      - isActive (boolean)
      - createdAt (timestamp)
      - lastLogin (timestamp)

[ ] 2.6 - Tạo indexes cho database
    - Order: orderId (unique), status
    - StatusLog: orderId, timestamp
    - BlockchainEvent: txHash, blockNumber
    - User: address (unique)

📋 GIAI ĐOẠN 4: REST API ROUTES
================================================================================

[ ] 4.1 - Routes Đơn Hàng
    File: src/routes/orders.js
    
    Endpoints:
      GET /api/orders
        Query: ?status=CREATED&limit=10&skip=0
        Response: { orders: [...], total: number }
      
      POST /api/orders
        Body: { orderId, metadataHash, adminAddress }
        Response: { success, txHash, order }
        Gọi: contract.createOrder()
      
      GET /api/orders/:orderId
        Response: { chi tiết order + history }
      
      PUT /api/orders/:orderId
        Body: { status, detailsHash }
        Response: { success, txHash }
        Gọi: contract.updateOrderStatus()
      
      DELETE /api/orders/:orderId
        Response: { success, txHash }
        Gọi: contract.cancelOrder()

[ ] 4.2 - Routes Trạng thái
    File: src/routes/status.js
    
    Endpoints:
      GET /api/orders/:orderId/history
        Response: { statusUpdates: [...] }
      
      GET /api/orders/:orderId/events
        Response: { blockchainEvents: [...] }

[ ] 4.3 - Routes Thống kê
    File: src/routes/stats.js
    
    Endpoints:
      GET /api/stats
        Response: {
          totalOrders,
          pendingOrders,
          completedOrders,
          cancelledOrders,
          lastUpdated
        }
      
      GET /api/stats/by-status
        Response: { status -> count mapping }

[ ] 4.4 - Health Check
    GET /api/health
      Response: {
        status: "ok",
        database: "connected",
        blockchain: "connected",
        uptime: seconds
      }

📋 GIAI ĐOẠN 6: SYNC SỰ KIỆN BLOCKCHAIN
================================================================================

[ ] 6.1 - Setup Lắng nghe Sự kiện
    Bắt đầu lắng nghe contract events:
      - OrderCreated
      - OrderStatusUpdated
      - OrderCancelled
      - AdminAuthorizationChanged

[ ] 6.2 - Hàm Xử lý Sự kiện
    Khi OrderCreated event được phát hành:
      1. Parse event data
      2. Kiểm tra order tồn tại trong DB
      3. Nếu không, insert order mới
      4. Lưu event vào BlockchainEvent collection

    Khi OrderStatusUpdated event được phát hành:
      1. Parse event data
      2. Cập nhật Order status trong DB
      3. Thêm vào StatusLog collection
      4. Lưu vào BlockchainEvent

[ ] 6.3 - Sync Worker
    File: src/services/eventListenerService.js
    Chạy như background service:
      - Kết nối blockchain
      - Poll events (interval-based) hoặc WebSocket
      - Xử lý events
      - Retry lại sync thất bại
      - Logging

[ ] 6.4 - Tích hợp Startup
    Trong server.js:
      1. Kết nối MongoDB
      2. Kết nối blockchain
      3. Bắt đầu event listener
      4. Bắt đầu Express server

     "success": true/false,

6. Chiến lược Xử lý Lỗi:
   - Validation errors: 400
   - Unauthorized: 401
   - Not found: 404
   - Server errors: 500
   - Contract errors: 500 + detailed message
