📝 NOTES FOR FRONTEND DEVELOPER

1. Contract ABI location:
   blockchain/artifacts/contracts/OrderTracking.sol/OrderTracking.json

2. Contract Address (Sepolia):
   0x5663b4AF89cFBFf92A29F8cb53516B705eF055C8

3. Contract Functions Available:
   - createOrder(orderId, metadataHash)
   - getOrder(orderId)
   - updateOrderStatus(orderId, newStatus, detailsHash)
   - getOrderHistory(orderId)
   - cancelOrder(orderId)
   - setAdminAuthorization(admin, status)

4. Events to Listen:
   - OrderCreated
   - OrderStatusUpdated
   - OrderCancelled
   - AdminAuthorizationChanged

5. MetaMask Requirements:
   - Users need MetaMask extension installed
   - Must be on Sepolia network
   - Need testnet ETH for gas (free from faucet)

6. Backend API (to be created):
   - Base URL: http://localhost:3000/api
   - Endpoints for order CRUD
   - WebSocket for real-time updates (optional)

7. Error Handling:
   - MetaMask not installed
   - Wrong network selected
   - Insufficient gas
   - Transaction failed
   - Contract validation errors

8. Performance Considerations:
   - Cache contract calls where possible
   - Use React.memo for expensive components
   - Pagination for large lists
   - Lazy loading for routes
